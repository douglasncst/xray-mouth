# Roadmap

## 0.1 — Foundation

- [x] Dataset inventory and reproducible JSON reports
- [x] Raster quality indicators
- [x] Basic DICOM de-identification
- [x] Tests, CI, contribution and security policies

## 0.2 — Reproducible pipelines

- [ ] Configurable preprocessing manifests
- [ ] Dataset-level duplicate detection
- [ ] Structured validation profiles
- [x] Synthetic example dataset and tutorial

## 0.3 — Evaluation

- [ ] Model-agnostic evaluation interfaces
- [ ] Calibration and subgroup reporting helpers
- [ ] Reproducible benchmark manifests
- [ ] Documentation for limitations and dataset shift

## Non-goals

The project will not offer diagnoses, treatment advice, or unvalidated clinical performance claims.
