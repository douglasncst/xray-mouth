# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for vulnerabilities involving patient data, path traversal, unsafe file parsing, secret exposure, or dependency compromise.

Include affected versions, reproduction steps using synthetic data, impact, and any proposed mitigation. You can expect an initial response within seven days. No bounty is currently offered.

## Sensitive data

Never attach real clinical files or identifiers to an issue, pull request, or security report. Use synthetic fixtures only.
