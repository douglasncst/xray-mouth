# Hardware integration status

XRay Mouth currently accepts a folder of image files only. Future work may target TWAIN-based acquisition, pending physical testing of the actual sensor and vendor driver.

No direct device, TWAIN, USB, vendor SDK, or proprietary protocol integration is shipped. The project does not claim Flyer HDR compatibility. Vendor drivers, calibration software, and their documentation remain authoritative until an adapter is tested with real hardware.
