# Pasta de entrada

`Caso_Anonimo` contem um exemplo autorizado com exatamente 14 radiografias,
regravadas sem metadados e nomeadas com prefixos de `01_` ate `14_`.

Para outro exame, crie uma subpasta local. Radiografias reais e dados de
pacientes nao devem ser enviados ao GitHub sem desidentificacao e autorizacao
explicita. O `.gitignore` protege novas subpastas desta pasta por padrao.
